{{ r.rank }} {{ '%.2f'|format(r.score) if r.score is not none else '—'|safe }} {{ '%.2f'|format(r.vina_energy) if r.vina_energy is not none else '—'|safe }} {{ '%.2f'|format(r.gnn_pec50) if r.gnn_pec50 is not none else '—'|safe }} {{ '%.2f'|format(r.rmsd) if r.rmsd is not none else '—'|safe }} {{ '%.2f'|format(r.centroid_distance) if r.centroid_distance is not none else '—'|safe }} {{ '%.2f'|format(r.shape_rmsd) if r.shape_rmsd is not none else '—'|safe }} {{ '%.2f'|format(r.closest_contact) if r.closest_contact is not none else '—'|safe }}

Score and Vina in kcal/mol; RMSD, Centre, Shape and Contact in A. RMSD is to the crystal ligand where it lies. Centre is the distance between the two centroids: it says whether the pose is in the right pocket at all. Shape is the RMSD after superposing the two ligands freely, which throws the placement away and asks only whether the molecule is folded the same. A low Centre and a low Shape beside a high RMSD is a ligand in the right site, turned the wrong way round. Contact is the closest heavy-atom approach to the receptor; under 2.2 A is a clash. Pose 1 went to MD; a highlighted row below it is the pose nearest the crystal.
